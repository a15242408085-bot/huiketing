# 会客厅 · 竹绿动效演示

会客厅是一份连接游客与独立小店的 AI 接待产品原型。游客可以选择地区、小镇和店铺，提出到店前的问题，生成第一次到店卡；店主可以维护资料，查看游客问题与内容建议。

本仓库整理了既有单文件原型和独立的原生 JavaScript / CSS 视觉增强源码。地区、店铺和体验数据用于演示，不代表真实经营信息。公开版本的八个影像位与海岸卡片均使用同一张 AI 生成竹林图作为可替换示意，不含第三方实拍照片。

## 构建与打开

需要 Python 3.9 或更新版本，不需要安装 Python 依赖或 npm 包。

```sh
python3 build.py
```

构建后直接打开 `dist/会客厅-Demo1.0.html`。产品介绍页是 `dist/会客厅-Demo1.0-产品介绍.html`，两份文件保留在同一目录即可使用页面间的介绍链接。每份 HTML 的样式和所需示意图已内嵌。Google Fonts 保留原型设置，离线时使用系统字体回退。

如果本机安装了 Node.js，构建脚本会额外运行 `node --check` 检查增强脚本语法；未安装也可以完成构建。

## 四个独立视觉增强

- **丝绸标题**：原生 SVG 噪声、微小位移和克制反光，保留原标题文字与字体度量。
- **竹林景深**：在竹林背景上进行轻微的推进与景深变化。
- **影像流**：地区页展示八个示意图位，可以暂停、预览，按 Escape 关闭预览。
- **地区卡片视差**：只移动卡片的装饰配图，原有文字、按钮和点击区域保持原位。

这些增强没有安装或复制 React Bits 付费组件源码，不依赖 CDN 或 WebGL。系统启用“减少动态效果”时显示静态效果；页面隐藏时暂停动画。增强不参与原有到店卡打印内容。

## 默认回答与在线模型

公开原型中的前端模型凭据已清空。原型已有的本地演示回答回退仍可使用，它不等同于在线大模型回答，也不表示真实店铺已经确认了回答。

本仓库不提供模型后端。如果需要在线模型，请自行实现服务端接口并接入原型的请求边界，将凭据保留在服务端。不要把服务端凭据放进 HTML、前端 JavaScript、构建数据或 Git 历史。

## 文件结构

```text
original/                 清除凭据后的既有单文件原型
src/                      独立视觉增强 JS / CSS
assets/bamboo-water-town.png  AI 生成竹林示意图
pubphoto-manifest.json     八个示意位和海岸占位的图片配置
build.py                  单文件构建脚本
dist/                     可直接打开的构建结果
licenses/                 原型所涉第三方许可文本
```

`original/` 中的应用代码已经打包，本仓库没有其原始前端工程、包版本清单或依赖锁文件。构建只追加视觉样式、数据与增强脚本，不重写原型业务逻辑。`dist/源码校验.json` 记录相对于已脱敏原型的校验结果。

## 替换自有授权图片

在 `assets/` 中放入自己拥有公开使用权的 PNG、JPEG 或 WebP 图片，再修改 `pubphoto-manifest.json` 中对应的 `asset`、`title`、`alt` 和 `theme`。地区配图按“江南”“山野”“海风”主题选择，海岸项保留 `role: "coast_reference"`。

请同时更新 `src/contact-sheet.js` 中的示意说明，使图片来源与实际授权一致。可以为自有图片填写 `photographer` 与 `source_page`，预览会展示这些说明。不要使用真实店铺名称暗示虚构演示店铺与该图片有关。

默认的竹林占位在构建 JSON 中只保存一次，其余示意位使用内部引用。`.gitignore` 默认忽略 JPEG 照片和私有配置；公开图片前请确认授权，再按需调整忽略规则。
