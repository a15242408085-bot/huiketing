# 会客厅Demo 3.0

连接游客与独立小店的可交互 Web 原型。内含首页、地区与小镇、五店详情、资料问答、到店卡及店主工作台。

## 打开与构建

直接双击 `dist/会客厅Demo 3.0.html`。页面图片、样式和增强脚本均已内嵌，可离线预览；网络字体不可用时使用系统字体。

```sh
python3 build.py
```

Python 3.9+，无 Python/npm 依赖。安装 Node.js 时会额外校验 JavaScript 语法。两份 HTML 放在同一目录，可使用产品介绍互链。

## 已实现

- 深墨青绿色主题、横排丝绸标题、半透明统计标签。
- 透明游客与写实店面破形入口、真实竹子前景和轻雾。
- 原位渐隐导航、地区目录直接上滑与无缝衔接。
- 全幅景点照片流、暂停与预览，以及地区配图视差。
- 按五家店名对应的三栏详情页、店铺介绍、示意平面图和原生聊天。
- “今天怎么过”条件选择、六种处境、可编辑问题草稿；确认后仅预填问答，不自动发送。
- 店主看板接回原资料、问题和内容工坊；统计及天气示例均有标注。

保留原型功能 bundle，仅追加独立视觉与交互模块。构建会逐字节校验：移除新增块后恢复已脱敏原型；原功能脚本与 CSS 保持一致。原型在线模型凭据已清空，公开版使用原有本地演示回答回退，不代表真实店主确认或线上模型服务。

## 素材与许可

项目自有代码、构建与文档采用 MIT；原型内第三方代码遵循原许可，见 THIRD_PARTY_NOTICES.md 和 licenses/。

`scenic-manifest.json` 记录六张 Unsplash 许可风景的摄影师、原始页面和许可。它们属于风景参考，不对应虚构店铺。用户同意在花瓣无法访问时使用这些无水印原图。

`room-editorial.json` 记录用户提供的五张 AI 设计参考，平面图通过 CSS 裁切呈现，非实际测绘；图片中的人物不代表真实店主。透明竹子由用户提供，游客与写实店面为本次 AI 生成素材。素材不因代码 MIT 许可而改变其原有权利与使用条件。

公开版本不包含私人本地原型的喜安屋参考照片、特色店实拍和接口凭据。

## 文件

`src/` 为独立模块，`original/` 为清除凭据后的原型，`assets/` 为公开素材；`build.py` 输出单文件 HTML 到 `dist/`。图片较多，单个 HTML 约 46 MB。
